# DefectIQ 5-minute demo

## Opening
"QA engineers often create defects like: Payment is not working after OTP. Please check ASAP. DefectIQ converts that vague report into a structured, measurable and developer-ready defect."

## Demo
1. Open the UI.
2. Keep the sample defect.
3. Click **Enhance with AI**.
4. Show:
   - before/after quality score
   - generated steps
   - expected and actual result
   - severity/priority
   - missing information
   - clarification questions
5. Save the defect.
6. Submit a similar defect to demonstrate duplicate detection.
7. Open History.

## Technical story
The system combines:
- AI enhancement pipeline
- deterministic quality validation
- missing-field rules
- similarity-based duplicate detection
- persistent defect history

## Closing
"DefectIQ does more than rewrite a sentence. It makes defect quality measurable and gives QA a repeatable path from a vague report to a reproducible engineering artifact."
